## Подготовленная тестовая копия

`build/three-mods-test/reVC.exe` — запускатель. Рядом должны оставаться
`reVC-game.exe`, `reVC-core.dll`, x86 звуковые библиотеки и наш x86 Mod Loader.
Не запускайте bootstrap напрямую и не подменяйте системные DLL старыми
`d3d8.dll`/`dinput8.dll` из комплектов для оригинального EXE.

```text
three-mods-test/
  reVC.exe
  reVC-game.exe
  reVC-core.dll
  modloader.asi
  modloader/
    .data/                         # наш согласованный комплект плагинов
    Remastered Interface/          # только TXD/DFF
    Ferrari458Italia/
      banshee.dff
      banshee.txd
      handling.cfg                 # полный файл, изменена только BANSHEE
  legacy-asi/
    enabled.ini
    LSDCXX_WeaponWheelVC.asi
    LSDCXX_WeaponWheelVC.ini
    weapvww/
```

Игра использует ссылки на существующую рабочую копию ресурсов в `build/`;
она не является автономным дистрибутивом с игровыми файлами. Не изменяйте
содержимое связанных каталогов `models`, `data` и т. п. вручную.

## Remastered Interface

В `reVC.ini` тестовой копии включены:

```ini
[Interface]
MoneyLeadingZeros=0
[Loading]
ScreenCount=14
```

По умолчанию `MoneyLeadingZeros=1`, `ScreenCount=0` сохраняют старое поведение.
Явное число экранов ограничено 64; отсутствующий экран не вызывает бесконечный
цикл открытия файла. Имена ресурсов — `loadsc0` … `loadsc13`.

`loadsc.asi` из архива патчит инструкции оригинального EXE и читает адреса
GTA III ещё до определения VC. Его нельзя запускать как обычную функцию ABI;
этот конкретный бинарник отклоняется до исполнения с объяснением замены.
19-байтовый `d_moneyHUD.cs` заменяет одну цифру ширины в формате денег. Обе
функции выполнены нашим кодом: CLEO и этот ASI не устанавливаются.

Пакет содержит английский `fonts.txd`, не полноценный HD-набор кириллицы.
Для языков с `fonts_r.txd`/другими словарями сохранится соответствующий
исходный шрифт, если пользователь отдельно не установит совместимые ресурсы.

Нативные изменения и ресурсный путь не требуют Windows x86 ABI, поэтому
доступны обычным сборкам Windows и Linux. Linux-запуск здесь не выполнялся.

## Оригинальный Weapon Wheel

Бинарник и PNG не переписываются и не перекомпилируются. Добавлены 29
адаптеров, `drawHud` и девять mouse/look CALL-точек; оригинальные объекты
CPed/CPlayerPed/CWeapon представлены проверенными теневыми структурами.
Прямые патчи двух функций переключения оружия учитываются native-вводом.
Нативные указатели librw/игровых объектов не выдаются за оригинальные объекты.

Tab нужно **удерживать**, а не просто нажать. Мышь выбирает сектор, отпускание
закрывает колесо. По исходному INI оригинальное переключение оружия отключено;
параметр `DisableVanillaWeaponSwitch` позволяет изменить это при закрытой игре.

Это только отдельная Windows x86-сборка D3D9/GL3. Для x64/WGPU и native Linux
Windows ASI не поддерживаются. Дополнительные ограничения фиксированного
bootstrap и ASLR описаны в [LegacyASI.md](LegacyASI.md).

## Ferrari

Скрипт `utils/modloader/prepare-resource-mod.ps1` принимает именно проверенный
архив и создаёт **новый** каталог внутри `build/`. Он не запускает мод,
не меняет IMG и исходный handling. Названия `Ferrari_458_UC.*` преобразуются
в `banshee.*`; 33-польная строка BANSHEE вставляется в полный файл, что также
безопасно для Linux backend с заменой handling целиком.

В модели 20 геометрий; все 14 ссылок на текстуры найдены в TXD из архива.
Это generic DFF RW 3.3 и PC D3D8 TXD, не SA native/skin-модель. Дополнительный
комплект общих HD-колёс сохранён в `optional-mods/`, **не включён**: он влияет
и на другие автомобили, а не только на Ferrari.

Файлы мода не добавляются в репозиторий или CI-артефакты. Для использования
на другой машине нужен собственный архив и законная копия игровых данных.

## Тесты собственного кода

`utils/modloader/test-resource-parsers.cmd` собирает и запускает наши тесты
ограниченного чтения/handling и нативных UI-настроек. Локально x86/x64
парсер прошёл по 563 проверки, UI-тесты — без ошибок. Для CI добавлена
проверка переносимых helpers на Windows и Linux без игровых файлов и без
скачанных ASI. Нативный Linux-компилятор локально не устанавливался.
